
# SauceDemo - Cypress E2E Tests

End-to-end test automation project using Cypress and JavaScript.

## About the Project

This project demonstrates automated testing of the
SauceDemo web application.

## Test Scenarios

### Login Tests
- Valid login with correct credentials
- Invalid login with incorrect password
- Error message validation
- URL validation after login

## Technologies
- Cypress
- JavaScript
- Node.js
- Git & GitHub

## How to Run

1. Clone the repository.
2. Install dependencies:

   npm install

3. Run tests:

   npm test

4. Open Cypress interactively:

   npm run cy:open
